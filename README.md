## 開啟方式

使用 GitHub 的 Code → Download ZIP，解壓縮後用支援 WebGL 的 Chrome 或 Edge 開啟任一 HTML。Three.js 與遊戲程式已內嵌，不需要啟動伺服器。GitHub 檔案頁不會直接執行遊戲。

## 小遊戲 2.0

- 車身以 Higgsfield 3D Jutsu 建模，比例依中山33（BRONTO SKYLIFT F 32 RPX）照片估算：兩軸、轉台在車尾、駕駛室後方有臂架托架。
- 收車姿勢比照實車：第一臂水平跨過駕駛室架在托架上，二臂往回摺疊平貼第一臂下方，平台收在車身中段。收車時平台不站人，第一視角從甲板開始，二臂展開後才登上平台。
- 展開順序：先升第一臂（建議 60° 以上）→ 展開二臂 → 旋轉轉台 → 調整仰角與伸縮。順序錯誤時車頭保護或碰撞檢查會停止動作。
- 平台內的 3D 控制台可直接拖曳搖桿；場景下方另有輔助控制台與鍵盤操作。

## 範圍

本遊戲為教學示意，車身尺寸、動態與控制台均非原廠認證模型，不提供實車荷重曲線或操作依據。作業範圍與載重設定依原廠手冊概略描繪；橋下情境為概念展示，本隊 33 車不適用。
