## 開啟方式

使用 GitHub 的 Code → Download ZIP，解壓縮後用支援 WebGL 的 Chrome 或 Edge 開啟任一 HTML。Three.js 與遊戲程式已內嵌，不需要啟動伺服器。GitHub 檔案頁不會直接執行遊戲。

## 控制台版本

控制台位於場景下緣，可以收合。左右搖桿及方向按鈕接入原有遊戲動作，放開即停；另有慢速、停止／解除停止、平台置中與任務操作。射水仍需符合遊戲原有條件。

左搖桿：上推第一臂下降、下拉上升，左推第二臂上升、右推下降。右搖桿：上推伸出、下拉收回，左推轉台左轉、右推右轉。

## 範圍與版本

本遊戲為教學示意，車身尺寸、動態與控制台均非原廠認證模型，不提供實車荷重曲線或操作依據。使用者確認車輛品牌為 BRONTO；既有遊戲部分畫面仍保留舊專案 VEMA 32F 名稱，確切車型尚未核定。

無控制台版由同一套建置程式移除新增控制台模組後產生；可操作控制台版為已驗證離線檔案的完整複本。各 HTML 的大小與 SHA-256 記錄在 [版本紀錄.json](版本紀錄.json)。

Three.js 的授權文字保留於各 HTML 檔案中。
