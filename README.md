## 開啟方式

- **線上**：用 Chrome 或 Edge 開 [https://fire1192335-droid.github.io/bronto-training-game/](https://fire1192335-droid.github.io/bronto-training-game/)，選要玩的版本，不需要安裝或啟動伺服器。
- **下載**：GitHub 的 Code → Download ZIP，解壓縮後：
  - 1.0、2.0：用支援 WebGL 的 Chrome 或 Edge 開啟 HTML 即可（Three.js 與遊戲程式已內嵌）。
  - 3.0：雙擊 `小遊戲3.0\啟動遊戲.bat`。它在本機開一個只供自己使用的伺服器（`127.0.0.1`）並開啟瀏覽器；關閉那個黑色視窗即停止。3.0 由多個模型、貼圖與影片檔組成，瀏覽器不允許直接從資料夾載入，所以直接雙擊 `index.html` 會顯示「請改用 啟動遊戲.bat 開啟」。
- GitHub 的檔案頁面不會執行遊戲。

## 小遊戲 3.0

遊戲規則、四個情境、碰撞與作業範圍、控制台與測驗都與 2.x 相同，換掉的是畫面：

- 雲梯車與平台控制台依中山33（BRONTO SKYLIFT F 32 RPX）照片以 Higgsfield 3D Jutsu 重建；臂架、轉台、腳架隨操作即時動作。
- 街景：透天街屋與騎樓、目標建築、行道樹與街道物件、橋與河岸、遠景天際線。
- 特效：水砲水柱與水花、窗口火焰與濃煙（射水後轉白色蒸氣）、腳架揚塵、警示燈與作業燈、落灰與火星。
- 受困者：陽台或邊坡上揮手求救，救上平台後蹲坐。
- 影片：每個情境開始前播一段約 6 秒的開場（可按「跳過」或 Esc，也可在情境選單關閉），標題畫面背景為循環影片。
- 畫質分高、低兩級，依裝置自動選擇，也可手動切換。

需要支援 WebGL 的桌上型電腦瀏覽器（Chrome、Edge）；手機與平板未經驗證。

## 範圍

本遊戲為教學示意，車身尺寸、動態與控制台均非原廠認證模型，不提供實車荷重曲線或操作依據。作業範圍與載重設定依原廠手冊概略描繪；橋下情境為概念展示，本隊 33 車不適用。

各 HTML 的大小與 SHA-256，以及 3.0 資料夾的檔案數與總大小記錄在 [版本紀錄.json](版本紀錄.json)；3.0 每個檔案的 SHA-256 在 [小遊戲3.0.sha256](小遊戲3.0.sha256)（可用 `sha256sum -c 小遊戲3.0.sha256` 檢查下載的檔案）。Three.js 的授權文字保留於各 HTML 與 `小遊戲3.0/vendor/three.module.min.js` 中。
